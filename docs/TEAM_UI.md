# 팀 편성 UI

2026-10-14 UI 개편. 전투 규칙과 저장 스키마는 유지한다.

## 배치와 조작

- 팀 선택·추가는 상단에 두고 데스크톱 본문은 왼쪽 현재 팀, 오른쪽 캐릭터 목록의 2열로 구성한다.
- 데스크톱 작업 영역 높이는 Navigation과 상단 도구 영역을 제외한 현재 viewport 공간에서 계산한다. 캐릭터 목록은 제목 아래에서 독립 스크롤한다. 전체 body 스크롤은 막지 않는다.
- 720px 이하에서는 1열로 전환하고 캐릭터 패널에 60vh 높이를 사용한다. 팀 편성 영역도 내부 스크롤 상한을 둔다.
- 캐릭터 카드를 현재 팀 영역으로 드래그하면 초안에 추가한다. 장비 화면의 native drag/setDragImage 패턴을 따라 초상화와 이름만 미리보기에 담는다.
- 드롭 가능·불가와 hover를 표시한다. 종료·취소 시 임시 요소와 강조를 제거하며 목록 재렌더링 시 scrollTop을 복원한다.
- 클릭으로 추가/제외하거나 편성 행의 제외 버튼을 사용할 수 있다. 중복 추가 금지·최대 10명 검사를 클릭과 드롭이 공유한다. 저장 버튼으로 기존 팀 API에 반영한다.

## 데이터와 표시 범위

- 선봉/예비대 인원, 전투 규칙 배율, 팀별 이전 배율 시너지 편집 UI를 제거했다. 저장된 activeMemberCount/battleRules/synergyRules와 런타임 적용은 유지한다.
- 저장 시 UI에서 변경하는 필드는 memberIds뿐이다. 기존 normalizeTeamJson의 인원 범위 보정은 유지하므로 팀원이 줄면 activeMemberCount가 기존 규칙에 따라 제한될 수 있다.
- 활성 시너지는 공용 synergiesJson/evaluateSynergies의 결과만 표시한다. 미저장 편성 추가·제외에도 즉시 갱신하고 이전 배율 시너지는 표시하지 않는다.
- 개인 CP는 기존 getCharacterCombatPower/formatCombatPower를 재사용한다. 이 지표에는 팀 시너지가 포함되지 않는다.
- 공식 팀 CP 집계 API/계약이 없어 팀 CP는 `— / 팀 계산 기준 준비 중`으로 표시한다. 개인 CP 합계를 팀 CP로 정의하지 않는다.

## 검증 상태

- 변경 전 실제 Chrome에서 기존 목록이 전체 페이지 높이를 늘리는 구조를 조사했다.
- 중단 전 CP/시너지 Node 검증 13개는 통과했다. 새 팀 UI 브라우저 검증은 ChromeDriver 확보 환경 문제로 완료하지 못했다.
- 최신 작업 규칙에 따라 재개 후 자동 테스트를 반복하지 않고 JS 문법·DOM 참조·변경 diff를 정적으로 확인한다.
- [브라우저 검증 시나리오](../tests/test_team_ui.py)는 복사 데이터 기반으로 준비했다. 변경 후 실제 드래그, 저장/새로고침, 시너지 갱신, 1920/1440/640px 화면 검증은 미완료이며 통과로 기록하지 않는다.
