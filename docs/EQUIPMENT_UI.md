# 장비 착용 인벤토리 UI

2026-10-10 현재 구현. 게임 규칙과 데이터 형식은 변경하지 않았습니다.

## 화면과 사용법

- PC는 캐릭터 목록 / 캐릭터 장비 / 인벤토리의 3영역입니다. 캐릭터 목록 폭은 최대 16%로 제한하고 인벤토리는 최소 40%를 확보합니다. 1100px 이하에서는 캐릭터 선택을 상단에, 700px 이하에서는 모든 영역을 세로로 배치합니다.
- 인벤토리에서 슬롯 필터와 이름 검색을 함께 사용할 수 있습니다. 68px 아이콘과 짧은 이름을 표시하며, 긴 이름은 말줄임과 기본 툴팁으로 확인합니다. 클릭하면 선택 테두리와 상세 능력치, 장착 가능한 슬롯이 표시됩니다.
- 아이콘은 기존 아이콘 관리의 무기/방어구 카테고리 매핑을 사용합니다. 카테고리가 없는 경우 슬롯 매핑을 사용하며, 이미지가 없으면 기존 표시명 fallback을 유지합니다. 아이템별 iconId나 새 이미지 저장소를 만들지 않았습니다.
- 아이템 아이콘을 장비 슬롯에 끌거나, 아이템을 선택한 뒤 슬롯 아이콘을 클릭하여 장착합니다. 세트 선택·복제·삭제는 슬롯 위 도구 모음에서 처리합니다.
- 작은 해제 버튼을 유지합니다. 장착된 아이콘을 인벤토리로 끌어도 기존 해제 함수가 실행됩니다. 인벤토리는 소모되는 소유 수량이 아니라 기존 전체 아이템 카탈로그이므로 장착 후에도 목록에 남습니다.
- 능력치 표는 아래 공통 영역에 압축하고 접을 수 있게 했습니다. 기본·장비 적용·변화 값을 유지하며, 0이 아닌 변화량은 기호와 강조색으로 표시합니다.
- 2026-10-14 장비 세트 선택 바로 아래에 종합전투력의 **무장비 → 현재**와 차이를 추가했습니다. 장착·해제·세트 변경 후 공통 계산기로 즉시 갱신합니다. 아이템 선택 단계의 교체 예상 미리보기는 없으며 무장비와의 차이는 직전 장비와의 차이가 아닙니다. [공식·한계](balance/COMBAT_POWER.md).
- 별도 아이템 관리의 생성/수정/삭제 편집기는 기존대로 유지합니다.

## 드래그 원인과 처리

기존 구현은 텍스트만 있는 `tr` 전체에 `draggable`을 지정하고 `dragstart`에서 `text/plain` ID만 전달했습니다. `setDragImage`나 텍스트 선택 제한이 없어 브라우저 기본 행 스냅샷에 이름이 포함됐습니다. Pointer 기반 구현은 없었습니다.

현재도 HTML5 Drag & Drop을 사용합니다. 아이콘 요소만 복제해 `setDragImage`에 전달하며 이름·행·상세 설명은 복제하지 않습니다. 원본은 투명도만 낮추고, 장비 슬롯과 인벤토리 버튼 안에서만 `user-select: none`을 적용합니다. 이미지 자체의 기본 드래그는 막습니다.

장착 가능 여부는 `canEquipItemToSlot`을 그대로 호출합니다. 가능한 슬롯은 테두리, 불가능한 슬롯은 낮은 투명도로 구분하고 현재 드롭 위치를 더 강하게 표시합니다. 잘못된 드롭은 거부하고 클릭으로 잘못된 장착을 시도하면 기존 안내를 표시합니다. 성공 시 기존 장착·계산·저장 경로를 거쳐 슬롯과 표를 다시 렌더링합니다. 드롭·취소·드래그 종료·화면 재렌더 시 임시 미리보기와 강조를 정리합니다.

## 검증

- 기존 Node 장비 규칙 테스트: 양손 점유, 추가 무기 슬롯, 단일 슬롯 예외, 세트 정규화.
- [Chrome 회귀 테스트](../tests/test_equipment_ui.py): 실제 서버와 복사한 데이터로 한손검/방패 연속 장착, 새로고침 유지, 인벤토리 역방향 해제, 잘못된 상의 슬롯 거부, 텍스트 없는 이미지 미리보기, 선택 텍스트 없음, 임시 DOM 정리, 클릭 장착, 검색, 세트 복제·삭제를 확인합니다.
- 1920/1440/640px 창에서 화면 캡처와 가로 넘침·아이콘 클릭 영역을 확인합니다. Headless 화면 캡처에는 OS가 그리는 네이티브 드래그 커서가 포함되지 않으므로 미리보기 DOM 내용과 실제 드래그 이벤트로 검증합니다.
- 테스트 데이터는 임시 폴더에서만 저장하며 기존 캐릭터 데이터는 보존합니다. 실행: `python tests/test_equipment_ui.py` (Selenium과 Chrome/ChromeDriver 필요).

## UI 외 확인 사항

- 기존 권투장비 카테고리에는 치유서와 같은 이미지가 등록되어 있어 그대로 표시됩니다. 아이콘 관리에서 사용자가 교체할 수 있습니다.
- 로컬 Python 서버의 짧은 연결 대기열에서는 Chrome의 병렬 요청 일부가 간헐적으로 거부됐습니다. 테스트 서버만 대기열을 64로 설정했습니다. 제품 서버 코드는 이번 범위에서 수정하지 않았습니다.
