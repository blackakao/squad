# 캐릭터 관리 UI

2026-10-11 구현. 기존 캐릭터 필드와 능력치 계산, 전투 선택 구조는 유지합니다.

## 목록과 정렬

- 열 순서: 이름, 계열, 진영, 종합전투력, HP, MP, ST, 공격력, 마력, 이동속도, 공격속도, 시전속도, 방어력, 저항력, 사정거리, 수정.
- 2026-10-14 종합전투력 열을 추가했습니다. 최종 능력치를 공통 계산기로 평가하며 정수·천 단위 구분·비교 지표 툴팁과 숫자 양방향 정렬을 제공합니다. [공식·제외 요소](balance/COMBAT_POWER.md).
- 첫 셀에 44px 초상화와 강조된 이름을 함께 표시합니다. 이름 열을 넓게, 수치는 오른쪽 정렬로 배치하고 교차 행 배경과 hover를 적용합니다.
- 표 내부에서 가로·세로 스크롤하며 이름 열과 헤더가 고정됩니다. 관리 목록 체크박스와 일괄 삭제는 제거했습니다.
- 수정 이외 열 제목 전체를 클릭하면 첫 클릭 오름차순, 다음 클릭 내림차순입니다. 화살표와 aria-sort로 방향을 표시하며 키보드로도 실행합니다.
- 11개 능력치와 종합전투력은 숫자로, 이름·계열·진영은 한국어 표시 이름으로 비교합니다. 동점은 원본 순서를 유지합니다.
- 계열 필터와 정렬을 함께 적용합니다. 화면용 배열만 정렬하며 원본 배열이나 저장 파일 순서를 변경하지 않습니다. 수정 버튼은 원본 인덱스를 사용합니다.

## 수정과 삭제

기존 수정 필드를 유지하고 하단 왼쪽에 캐릭터 삭제, 오른쪽에 취소·저장을 배치했습니다. 신규 추가 창에는 삭제 버튼이 없습니다. 삭제 전 캐릭터 이름을 포함한 브라우저 확인창이 표시됩니다.

삭제 시 기존 팀 구성원 인덱스 정리와 전투 선택 초기화를 재사용합니다. 저장 중 중복 실행을 막습니다. 캐릭터 저장 실패 시 목록과 팀 참조를 복원하여 다시 시도할 수 있습니다. 캐릭터와 팀은 별도 API로 저장하므로 캐릭터 저장 성공 후 팀 저장 실패 시 팀 편성을 확인하고 재저장하도록 안내합니다.

## 검증

`python tests/test_character_ui.py`: 격리된 데이터 복사본과 실제 Python API·Chrome을 사용하는 5개 테스트 통과.

- 11개 숫자 열 양방향 정렬, 소수·자리수 차이, 원본 배열 및 파일 유지.
- 한글 3개 열 정렬, 계열 필터 결합, 정렬 후 올바른 수정 대상.
- 이름 확인과 삭제 취소, 신규 추가 창 삭제 숨김.
- 테스트 전용 캐릭터 삭제·팀 참조 저장·새로고침, 저장 실패 후 재시도.
- 정확한 열 구성, 키보드 정렬, 1920·1440·640px 화면과 가로 스크롤 시 이름 고정. 실제 스크린샷으로 목록과 수정 창 배치를 확인했습니다.

사용자 원본 데이터는 테스트에서 수정하지 않습니다. JavaScript 문법 검사도 통과했습니다.
