# 캐릭터 관리 UI

## 선택 강화 스킬 (2026-11-09)

- 캐릭터 행을 열고 **보유중인 스킬목록**에서 `선택 강화 (최대 3개)` 표시 항목을 체크한다. 기본 스킬과 별도로 최대 3개까지 선택할 수 있으며 네 번째 체크는 취소된다. **선택중인 스킬목록**에서 확인하고 저장한다.
- 선택한 강화만 해당 캐릭터에 적용된다. 혈청형은 성분혈·끝없는 피의 결계·혈액 효율성·광속흡혈·흡혈광·정신회복 중 선택한다. 최초 데이터에는 강화가 선택되어 있지 않다. 전투 전 종류 선택/룬 선택과 독립이다.
- 선택 ID는 기존 skillIds 배열로 저장하며, 스킬 미리보기와 전투에 같은 런타임 보정을 사용한다. [강화 수치와 규칙](SKILL_ENGINE.md#혈청형-개편캐릭터-선택-강화-2026-11-09).

2026-10-11 구현. 기존 캐릭터 필드와 능력치 계산, 전투 선택 구조는 유지합니다.

## 목록과 정렬

- 열 순서: 이름, 계열, 진영, 종합전투력, HP, MP, ST, 공격력, 마력, 이동속도, 공격속도, 시전속도, 방어력, 저항력, 사정거리. 행 클릭 또는 행에 초점을 둔 Enter/Space로 상세 창을 엽니다.
- 2026-10-14 종합전투력 열을 추가했습니다. 최종 능력치를 공통 계산기로 평가하며 정수·천 단위 구분·비교 지표 툴팁과 숫자 양방향 정렬을 제공합니다. [공식·제외 요소](balance/COMBAT_POWER.md).
- 첫 셀에 44px 초상화와 강조된 이름을 함께 표시합니다. 이름 열을 넓게, 수치는 오른쪽 정렬로 배치하고 교차 행 배경과 hover를 적용합니다.
- 표 내부에서 가로·세로 스크롤하며 이름 열과 헤더가 고정됩니다. 관리 목록 체크박스와 일괄 삭제는 제거했습니다.
- 열 제목 전체를 클릭하면 첫 클릭 오름차순, 다음 클릭 내림차순입니다. 화살표와 aria-sort로 방향을 표시하며 키보드로도 실행합니다.
- 11개 능력치와 종합전투력은 숫자로, 이름·계열·진영은 한국어 표시 이름으로 비교합니다. 동점은 원본 순서를 유지합니다.
- 계열 필터와 정렬을 함께 적용합니다. 화면용 배열만 정렬하며 원본 배열이나 저장 파일 순서를 변경하지 않습니다. 행 선택은 원본 인덱스를 사용합니다.

## 수정과 삭제

스킬 hover/키보드 초점 툴팁은 설명 텍스트와 수치 한 줄 요약을 표시합니다. 설명 누락은 `스킬 설명 없음`으로 드러내며 데미지·회복·소모·사정거리·재사용·시전·범위·지속·DPS를 함께 표시합니다. 좁은 화면은 줄바꿈하며 피해·회복은 대상 보정 전 비교값입니다. 선택형은 현재 선택한 유형 기준입니다.

명함형 상단은 왼쪽 진영·이름·계열과 각 아이콘, 오른쪽 큰 초상화로 구성합니다. 초상화를 누르고 편집 확인에 동의하면 이미지 편집 영역을 펼칩니다. 장비 목록에는 기존 장비 카테고리 아이콘을 사용합니다. 개체 등급 편집은 제거하며 저장 등급은 2입니다.

모달 바깥 클릭 또는 취소 시 변경이 없으면 닫고, 변경이 있으면 저장 후 닫기·저장하지 않고 닫기·계속 편집을 선택합니다. 변경 비교에는 기본 정보·스킬·유형 선택·초상화/외형 초안을 포함합니다. 저장 실패 또는 입력 검증 실패 시 모달을 유지합니다. 저장 중에는 중복 저장과 닫기를 차단합니다.

보유 스킬은 고정 표시로 활성/비활성을 전환하지 않습니다. 선택형(`choice_team`, `choice_prebattle`)만 클릭하면 모달 내부에 유형 선택지가 펼쳐집니다. 선택값은 캐릭터 `skillSelections`에 기본값으로 저장하며 팀/전투별 선택값이 우선합니다. 별도의 선택 강화 6칸은 기존 최대 3개 선택 및 반투명 표시를 유지합니다. 아래 아이콘 개편 이력의 보유 스킬 토글 동작은 이 규칙으로 대체합니다.

2026-11-09 스킬 표시 후속 개편: 보유 스킬은 패시브·기본 1~4·궁극기, 선택 강화는 별도 6칸으로 표시합니다. 아이콘 버튼을 클릭해 활성화/해제하며 비선택은 반투명, 선택은 불투명과 강조 테두리로 구분합니다. 선택 강화 최대 3개 규칙과 저장 형식은 유지합니다. 미등록 슬롯은 비활성 빈칸이며, 복수 선택형 패시브는 패시브 칸에 함께 표시합니다. 기본 스킬은 현재 클래스 목록 순서, 궁극기는 이름/ID의 궁극·ultimate 표시로 구분합니다. 보이지 않는 기존 선택 ID도 보존합니다. 키보드 Enter/Space와 기존 수치 툴팁을 지원합니다.

2026-11-09: 기본 정보 아래에 현재 능력치(HP/MP/ST/공격력/마력/방어력/저항력/공격속도/이동속도), 현재 착용장비, 보유 스킬, 선택 스킬을 표시합니다. 능력치는 기존 스탯·장비 합산을 사용하며 장비는 조회용입니다. 보유 스킬 체크로 선택 목록을 갱신하고 저장합니다. 기존 타 클래스 선택 스킬도 유지하며 스킬의 수치 툴팁을 재사용합니다.

추가 무기 슬롯·양손 한 슬롯·다중 무기 피해 감산, 진입/부활 규칙, 커스텀 자원 편집은 제거했습니다. 저장 시 기존 값은 보존하며 신규 캐릭터는 기본값을 사용합니다. 해당 설정의 스킬 이관이나 새 스킬 구현은 이번 UI 변경에 포함하지 않습니다.

하단 왼쪽에 캐릭터 삭제, 오른쪽에 취소·저장을 배치합니다. 신규 추가 창에는 삭제 버튼이 없습니다. 삭제 전 캐릭터 이름을 포함한 브라우저 확인창이 표시됩니다.

삭제 시 기존 팀 구성원 인덱스 정리와 전투 선택 초기화를 재사용합니다. 저장 중 중복 실행을 막습니다. 캐릭터 저장 실패 시 목록과 팀 참조를 복원하여 다시 시도할 수 있습니다. 캐릭터와 팀은 별도 API로 저장하므로 캐릭터 저장 성공 후 팀 저장 실패 시 팀 편성을 확인하고 재저장하도록 안내합니다.
