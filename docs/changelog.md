## 2026-10-10 · 블랭크 헤어 20종 연속 surface 및 모델 선택 정리

- 남성 01의 승인된 연속 숏컷 surface는 그대로 두고 남성 02~10, 여성 01~10에 서로 다른 front/side/back 종료각, crown 평탄도·굴곡·비대칭·볼륨 profile을 추가했습니다.
- 블랭크 20종에서 외부에 보이던 공통 `InternalScalpCover`, 분리형 Crown strand, 타원형 `Hairline` 생성을 제거했습니다. 각 스타일은 `CrownHair_<id>` 연속 surface가 정수리·측두부·후두부를 덮고, 앞머리·장발·묶음·땋은 머리는 스타일 파츠로 연결됩니다.
- 실제 WebGL에서 남성 10종과 여성 10종을 각각 정면, 좌측 45도, 좌측, 후방 45도, 후면, 상단으로 캡처해 피부 구멍, 뒤통수 노출, 독립된 타원형 덩어리가 없음을 확인했습니다.
- 여성 긴 생머리에서 허니 블론드 선택 후 투구를 장착해 Crown만 숨고 Side/Back이 유지되는지 확인했으며, 투구 해제 후 f2와 색상이 복원되었습니다.
- 여성 f2·허니 블론드 조합을 브라우저 저장소에 저장하고 다른 머리/색상으로 바꾼 뒤 다시 불러와 정확히 복원했습니다. 무작위 조합도 여성 블랭크를 유지했습니다.
- CharacterViewer의 빠른 모델 선택은 남성/여성 블랭크만 남겼습니다. 기존 GLB는 테스트·직접 링크·이전 저장 호환에서 참조하므로 파일을 삭제하지 않았습니다.
- Node 테스트 21개, Python 블랭크 모델 생성 테스트, JavaScript 문법 검사와 `python -m py_compile server.py`가 통과했습니다. 현재 환경에는 `pytest`가 없으며 Selenium 회귀는 ChromeDriver 자동 다운로드가 네트워크에서 차단되어 실행되지 않았습니다. 해당 시각 항목은 공유 브라우저에서 직접 검증했습니다.
