# 변경 기록

## 2026-10-18 · 전투 캐릭터 버튼 크기·적용 범위 수정

- 팀 vs 몬스터/팀 vs 팀의 내 캐릭터 버튼에도 클래스 초상화·계열 아이콘·이름을 적용했습니다. 1:1 버튼과 공통 렌더 함수를 사용합니다.
- 한 행 전체를 차지하던 1:1 버튼을 자동 너비·가로 줄바꿈으로 변경하고 아이콘을 20px로 줄여 기존 작은 버튼 높이를 유지합니다. 선택/전투 로직 변경 없이 문법·diff 정적 검사만 수행했습니다.

## 2026-10-18 · 1:1 캐릭터 선택 버튼

- 양쪽 캐릭터 선택을 버튼 목록으로 변경했습니다. 스킬 관리의 클래스 표시와 동일하게 캐릭터 초상화를 사용하고 계열 공통 아이콘·이름 순서로 표시합니다. 초상화가 없으면 첫 글자로 대체합니다.
- 선택 버튼의 배경과 aria-pressed를 갱신하며 기존 단일 선택·전투 처리를 유지합니다. JavaScript 문법 및 diff 정적 검사만 수행했습니다.

## 2026-10-18 · 캐릭터 1:1 대결

- 전투 방식에 캐릭터 vs 캐릭터를 추가했습니다. 아군/상대 한 명씩 선택하며 같은 캐릭터도 별도 유닛으로 대결합니다.
- 양측 선택 스킬을 독립 설정하고 기존 장비/스탯/스킬/공용 시너지 및 전투·결과 기록 경로를 재사용합니다. 이전 팀 인원·배율·예비대 설정은 1:1에 적용하지 않습니다. 소환은 기존 규칙을 유지합니다.
- 시작마다 양측을 다시 구성하고 한쪽 미선택이면 차단합니다. 초기화·캐릭터 삭제 시 양쪽 선택을 해제합니다. 사용자 데이터 스키마 변경은 없습니다.
- 핵심 참가자 구성 경로 변경에 대해 Node 전용 3개를 실행해 통과했습니다. 브라우저 시각 검증은 수행하지 않았습니다.

## 2026-10-18 · 선택 스킬

- 스킬 타입에 `팀편성 선택`과 `전투 직전 선택`을 추가했다. 선택 스킬은 선택지별로 기존 스킬을 참조하며 기본 선택지를 반드시 가진다.
- 스킬 편집기는 선택 타입에서 일반 비용·액션 대신 선택지 이름, 연결 스킬, 기본값을 편집한다. 목록에는 선택지 수와 기본 선택지를 요약한다.
- 팀편성 선택은 팀원 행에서 설정하고 `teams[].skillSelections`에 저장한다. 전투 직전 선택은 전투 화면의 선택 현황 아래에 해당 스킬을 모아 표시한다.
- 전투 유닛 생성 시 선택 결과를 실제 스킬 ID로 치환한다. 액티브와 패시브 모두 기존 실행 경로를 그대로 사용하고, 선택하지 않았거나 저장값이 유효하지 않으면 기본 선택지로 복구한다.
- 검증: `node --check`로 관련 JavaScript 4개 파일의 문법을 확인했고 `git diff --check`를 통과했다. 실제 브라우저의 임시 데이터로 두 신규 타입 노출, 선택 편집기 조건부 표시, 전투 직전 일괄 UI, 기본값 및 변경값의 런타임 치환을 확인했다. 실제 사용자 JSON은 변경하지 않았다.

## 2026-10-18 · 스킬 관리 목록과 수정 흐름 재구성

- 모달을 연 뒤 Bootstrap이 입력 요소에 CSS 클래스를 추가하면서 수정으로 오인하던 문제를 고쳤다. 변경 비교는 CSS 클래스와 무관한 DOM 순서·ID·name 및 실제 값·선택·체크·아이콘만 사용한다.
- 스킬 표는 이름 22%, 클래스 12%, 타입 10%, 스킬값 요약 28%, 설명 28%의 고정 레이아웃을 사용한다. 클래스·타입은 한 줄로 유지하고 이름·요약·설명에 더 넓은 공간을 배분했다.
- 실제 브라우저에서 모달을 열고 비동기 UI 보정 후에도 미수정 상태가 `false`로 판정되는 것을 확인했다. 1440px에서 표가 콘텐츠 폭을 채우고 페이지 가로 넘침 없이 설명 영역이 넓게 유지되는 것도 확인했다.
- 스킬 목록을 이름, 클래스, 타입, 스킬값 요약, 설명의 5개 열로 정리했다. 기존 `slot` 저장 필드는 그대로 유지하며 화면에서 베이직·액티브·패시브 타입으로 표현한다.
- 클래스는 명시적 `className`을 기준으로 동명의 캐릭터 초상화와 이름을 표시한다. 기본 무기 공격·기본 회복은 공용 배지를 사용하는 공용 스킬로 유지한다.
- 스킬값 요약은 자원 소모, 액션 계수, 재사용대기와 시전시간을 함께 표시한다. 목록 행을 클릭하거나 키보드 Enter/Space로 수정 모달을 연다.
- 목록 선택과 일괄 삭제를 제거하고 수정 모달 안으로 단일 삭제를 옮겼다. 기본 공용 스킬은 삭제 버튼을 표시하지 않으며, 관련 데이터 저장 실패 시 메모리의 스킬·캐릭터·몬스터·아이템 참조도 삭제 전 상태로 복원한다.
- 모달 바깥 영역이나 취소 버튼으로 닫을 때 실제 폼 변경을 비교하고, 변경된 경우 저장 후 닫을지 묻는다. 저장 검증이 실패하면 모달을 유지한다.
- 데이터 스키마와 전투 계산은 변경하지 않았다. JavaScript 문법과 diff 정적 검사를 통과했다.
- 실제 브라우저에서 40개 행과 5개 헤더, 클래스 초상화·공용 배지, 스킬값 요약, 행 클릭 수정, 기본 공용 스킬 삭제 보호, 일반 스킬 삭제 버튼, 바깥 클릭 변경 확인과 1440/600px 페이지 넘침 없음을 확인했다.
