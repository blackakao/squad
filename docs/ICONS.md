# 동일 카테고리 아이콘 관리

상단 **아이콘 관리**에서 분류와 대상 단어를 선택하고 대체 표시명, 이미지 경로 또는 업로드할 이미지를 지정한 뒤 **저장 / 적용**을 누릅니다. 같은 대상은 기존 설정을 수정합니다. **해제**하면 원래 이름으로 돌아갑니다.

- 분류: 잡 클래스, 장비 슬롯, 무기 카테고리, 방어구 카테고리, 스킬 유형, 진영.
- 대상은 현재 데이터에서 선택합니다. 클래스·슬롯·카테고리·스킬 유형은 내부 키로 연결하고 진영은 현재 이름으로 연결합니다. 진영 이름을 바꾸면 새 이름에 다시 지정해야 합니다. 삭제된 대상의 설정도 관리 목록에서 해제할 수 있습니다.
- 적용 화면: 캐릭터·몬스터 목록의 클래스, 캐릭터 목록의 진영, 진영 관리 목록과 소속 캐릭터 클래스, 팀 편성의 캐릭터 클래스, 아이템 목록의 슬롯·카테고리, 장비 착용 슬롯과 아이템 툴팁의 슬롯, 장비 카테고리 목록, 스킬 목록의 유형.
- 선택 상자, 설명 문장, 전투 상태·로그·Canvas는 원래 텍스트를 유지합니다. 문자열 전체 치환은 하지 않습니다.
- 아이콘은 32px로 표시하며 대체 표시명은 이미지의 대체 텍스트와 마우스 툴팁에 사용합니다. 표시명만 등록하면 텍스트를 바꿉니다. 이미지가 없거나 로드에 실패하면 표시명(없으면 원래 이름)을 표시합니다.
- 업로드: 5MB 이하 PNG/JPG/WEBP/GIF. 기존 `POST /api/assets/icons`로 저장합니다. 경로 입력은 `assets/images/`의 허용된 이미지 폴더만 지원합니다.
- 설정은 `GET/PUT /api/icon-mappings`를 통해 [icon-mappings.json](../data/icon-mappings.json)에 저장합니다. 초기값은 빈 배열입니다. 게임 데이터의 이름이나 전투 판정은 변경하지 않습니다.
- 저장 실패 시 적용 중인 설정은 유지하고 오류를 표시합니다. 초기 조회 실패 시 덮어쓰기를 막으며 화면을 다시 열면 조회를 재시도합니다.
- 설정 해제는 이미지 파일을 지우지 않습니다. 이미지 업로드 후 설정 저장이 실패하면 업로드된 파일이 남을 수 있습니다.

## 배경 자동 제거 (2026-10-09)

- 기존·신규 아이콘 모두 **배경 자동 제거**가 기본으로 켜집니다. 기존 설정 파일을 일괄 수정하거나 이미지를 다시 등록할 필요가 없습니다.
- 브라우저에서 가장자리의 대표 배경색을 추정하고, 가장자리와 연결된 유사색 영역만 투명하게 표시합니다. 내부에 둘러싸인 같은 색 장식은 유지하고 경계에 반투명 처리를 적용합니다. 이미 투명한 이미지는 그대로 표시합니다.
- **제거 강도**는 8~100, 기본 48입니다. 배경이 남으면 올리고 그림이 함께 지워지면 낮춥니다. 체크를 끄면 원본을 표시합니다. 변경 후 **저장 / 적용**을 눌러 설정을 유지합니다.
- 체크무늬 미리보기에서 결과를 확인합니다. 파일 선택, 경로 입력, 강도 변경 모두 실제 목록과 같은 처리를 사용합니다. 빠르게 대상을 바꿔도 마지막 선택의 미리보기를 유지합니다.
- 원본 업로드 파일과 기존 이미지 경로는 보존합니다. 투명 처리는 표시용 PNG로 메모리에 캐시하며 파일을 덮어쓰지 않습니다. 외부 API나 모델 다운로드 없이 동작합니다.
- 이 처리는 단색·유사색 배경용입니다. 복잡한 배경, 피사체와 같은 색의 배경, 내부에 갇힌 배경은 완전히 제거하지 못할 수 있습니다. 가장자리 색이 불규칙하거나 전체 그림이 사라지는 경우 원본을 유지합니다. 불투명 애니메이션 GIF가 처리되면 표시용 이미지는 정지 PNG가 됩니다. 애니메이션을 유지하려면 자동 제거를 끕니다.
- 표시용 처리는 긴 변 최대 384px이며 경로·강도별 최대 64개 결과를 캐시합니다. 처리 실패 시 목록에는 원본을 표시하고 로그를 기록합니다. 이미지 자체의 로드 실패는 기존 텍스트 대체 표시를 따릅니다.

구현은 [icons.js](../js/icons.js)와 [icon-background.js](../js/icon-background.js)입니다. Node 회귀는 [icons.test.cjs](../tests/icons.test.cjs), Chrome/Selenium과 격리된 Python API 저장 검증은 [test_icon_background.py](../tests/test_icon_background.py)에서 관리합니다. 2026-10-09 Node 7개와 브라우저 4개를 통과했고 실제 검 아이콘의 흰 배경 제거와 기존 투명 방패 아이콘 보존을 렌더로 확인했습니다.
