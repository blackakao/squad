# 목표 밸런스

현재 측정값이 아닌 사용자가 원하는 기준입니다. 아래 표의 **미정**만 숫자로 바꾸면 다음 실행부터 리포트에 반영됩니다. 양쪽이 미정이면 평가하지 않으며, 한쪽만 설정해도 됩니다. 숫자에 단위 기호를 붙이지 않습니다. 승률은 0–100(%), 전투시간은 초, DPS/HPS는 초당 실제 피해/HP 회복입니다.

## 목표 범위

| 지표 | 최소 | 최대 |
| --- | --- | --- |
| winRate | 미정 | 미정 |
| duration | 미정 | 미정 |
| dps.tank | 미정 | 미정 |
| hps.tank | 미정 | 미정 |
| dps.melee | 미정 | 미정 |
| hps.melee | 미정 | 미정 |
| dps.ranged | 미정 | 미정 |
| hps.ranged | 미정 | 미정 |
| dps.healer | 미정 | 미정 |
| hps.healer | 미정 | 미정 |
| dps.special | 미정 | 미정 |
| hps.special | 미정 | 미정 |

역할 키는 게임의 현재 role을 그대로 사용합니다: tank(1종 전투계열), melee(2종 전투계열), ranged(마법사), healer(지원가), special(특수). Dealer/Support 같은 새 역할 분류는 임의로 지정하지 않습니다. 역할 기준은 해당 역할의 각 캐릭터 평균 DPS/HPS에 적용됩니다.

예를 들어 원하는 승률이 47–53%라면 winRate 행의 최소를 47, 최대를 53으로 수정합니다. 이는 사용법 예시이며 기본 목표가 아닙니다.

## 밸런스 철학

미정. 목표 전투시간, 역할별 기여도, 조합 상성에 대한 기준을 여기에 기록합니다. 자유 서술문은 자동 평가하지 않습니다.

## 통계 해석

최소 표본 수는 실행 옵션 `--min-samples`(기본 30)로 설정합니다. 이는 리포트의 표본 경고 기준이며 게임 밸런스 목표가 아닙니다. 표본 부족 캐릭터는 수치 목표를 설정해도 평가를 보류합니다.
