상성
채집<약탈<수호

종류
채집: 적당한 피로도를 소모하고 안정적이게 자원을 수집하는 방식
약탈: 상당한 피로도를 소모하고 대량의 자원을 약탈하는 방식
수호: 적당한 피로도를 소모하고 극소량 혹은 적당향의 소지금을 취집

채집
- 지역의 자원 생산량/속도에 따라 채집량이 다름
- 한지역에 주둔중이 채집꾼들에 따라 채집량이 다름
- 채집할때는 약탈에 취약함
- 채집하다 약탈을 당할 경우 가까운 성도로 강제 귀환되고 n분의 휴식시간을 강제 받음
- 평판의 변화 없음
약탈
 - 약탈거리가 많을수록 수집량은 채집보다 높을수 있음
 - 상당한 피로도를 소모하고 불안정적이게 자원을 약탈함, 채집중인 대상의 자원을 가져옴. 채집하는 사람이 많아야 조우율이 높아짐
 - 평판이 감소
 - 전투력이 마을 주변의 경비병 보다 낮으면 두드려 맞고 끝날수 있음
 - 대신 경비병은 성도에서 멀어질수록 배치도가 낮음
 - 약탈하다가 수호나 경비병에게 패배할 경우 가까운 성도로 강제 귀환되고 n분의 휴식시간을 강제 받음
 - 또 약탈만 너무 많아서 약탈을 못할 경우 수입 제로
수호
 - 아무것도 뺏기지 않고 고정적인 수입을 취할수 있음
 - 평판이 증가
 - 약탈꾼을 체포하여 포상금을 받을 수 있음
 - 약탈군이 아무도 없으면 무일푼으로 돌아오고 경험치도 적음
