# 직업 스킬 등록과 엔진 확장 과제

공작은 `skill_class_duke_immortality`, `bomb_necklace`, `unfair_damage`, `cursed_nail`, `rapid_revival`을 장착한다. 선택 강화 6종은 캐릭터 창에서 최대 3개만 적용한다. [현행 수치](SKILL_ENGINE.md#공작반복-부활공통-패배-상태-2026-11-11).

영혼수확자는 `skill_class_soul_reaper_soul_and_body`와 `skill_class_soul_reaper_black_assault`를 장착한다. `skill_class_soul_reaper_soul_breath`는 영혼상태의 같은 1스킬 슬롯에 연결된 내부 변형이다. [수치·쿨다운](SKILL_ENGINE.md#영혼수확자치명상-형태-전환-2026-11-09).

각질형은 `skill_class_keratin_shell`, `molt`, `repulsive_shield`, `pity`를 사용한다. `skill_class_keratin_shield_burst`는 내부 파괴 반응 전용이다. [현행 계약](SKILL_ENGINE.md#각질형단계별-스택파괴-반응-보호막-2026-11-09).

정령술사는 `skill_class_spirit_choice`로 정령 종류를 고르고 `birth/sacrifice/burst/purify` 액티브와 `chaos_ultimate` 궁을 사용한다. 선택 6종 중 최대 3개를 장착하며 패시브 아이콘 오른쪽 아래에 생존 정령 수를 표시한다. 이전 `skill_class_spirit_summon`은 보존·장착 제외다. [현행 계약](SKILL_ENGINE.md#정령술사-개편-2026-11-09).


룬술사는 패시브 `skill_class_rune_master`와 룬일격 `skill_class_rune_strike`를 사용한다. 룬은 `data/runes.json`에 별도 등록하며 초기 달룬·초승달룬·총알룬·불꽃룬 중 전투 전에 3개를 고른다. [현재 구현](SKILL_ENGINE.md#독립-룬-시스템룬술사-2026-11-07).


현재까지 완료된 엔진 기능의 전체 목록은 [스킬 엔진 업데이트 내역](SKILL_ENGINE_CHANGELOG.md)을 참고한다.

> 후속 구현: 스킬별 시전시간(0초 즉시시전), 원형 광역, 독립 소환수와 예제 7개를 추가했다. [현재 엔진 안내](SKILL_ENGINE.md)가 아래 최초 등록 당시 설명보다 우선한다. 일반 광역·일반 소환·스킬별 시전시간은 이제 지원하며, 아래는 원안 전체의 구현 과제를 기록한 과거 목록이다.

[직업 원안](CLASS.MD)에서 현재 실행 가능한 효과를 순차 구현하고 있다. 최초 등록 당시 `skill_class_*` 스킬은 47개였으며, 이후 추가된 구현 범위는 아래 등록 내용과 엔진 변경 기록을 따른다.

## 편집과 기본값

스킬 화면에서 직업명으로 찾아 수치를 수정하고 캐릭터 수정 화면에서 장착한다. 액티브·패시브·선택·기본 슬롯을 지원하며, 원안의 기본스킬은 자동 평타용 basic 슬롯과 다르다. 직업별 장착 제한 및 기본 4개/선택 3개 제한은 아직 없다.

기본 쿨타임 8초, MP 또는 ST 소모 10, 공격력/마력 계수 100%, 강공 150%, 고정 피해 20, 자원 회복 20이다. 근접 사거리 1, 원거리 5, 저격 10이다. 사용자가 조정할 초기값이다.

(기본형)은 원안의 일부 효과만 동작한다는 뜻이다. 미지원 효과는 아래 직업별 표를 참고한다. BP 보호막은 만료되지 않는다. 검의 집중은 현재 공격 가능한 검마다 원래 공격력 50%를 적용한다. 사연격 기본형은 25%씩 즉시 4타다. 야전지구력은 즉시 자원 회복이며, 불꽃 명상은 무료 4초 채널링으로 매초 부족한 MP의 10%를 회복한다.

## 권장 확장 순서

1. **실행 기능과 편집기 일치**: 미지원 액션 잠금·지원 여부 표시, 스킬별 시전시간/즉시시전, 액션별 독립 대상·최소 거리·사거리 검증, 원형 반경·최대 대상 수·연쇄 대상 선정은 구현되었다. 적 피해와 아군 회복은 별도 대상과 투사체로 실행한다. 상세 동작은 [스킬 엔진 안내](SKILL_ENGINE.md)를 참고한다.
2. **시간 효과와 이벤트**: 상태/버프 인스턴스의 시전자, 대상별 보관, 지속시간, 중첩·갱신, ID/분류/전체 해제, 효과 부여 면역, 주기 피해·회복, 시전 중단과 공통 이벤트, 조건·확률·쿨타임 기반 패시브, 유지시간·간격·피격 중단을 갖는 채널링은 구현되었다. 패시브로 인한 다른 패시브의 발동은 차단한다.
3. **조건과 계산**: 액션별 대상 쿨타임과 대상 저HP 조건, 전투 누적 실제 피해량·이동 거리·대상 전체 또는 특정 ID 중첩·생존한 자기 소환수 수·패시브 발동 피해·지정 커스텀 자원 현재값 계수, 직전 액션과 현재 실행의 실제 피해·치유량 전달 및 액션 조합을 통한 피해↔치유 전환, 적중·피격·회복·시전 완료 기준의 다음 N회 소비 효과와 피해 무시, 시전자 자신의 실제 스킬 자원 지불량, 대상 HP·MP·ST·BP 감소와 실제 성공량 전달은 구현되었다.
4. **소환과 공간**: 소유자·수명·개체 제한·AI를 갖는 소환체, 지속 지역 효과, 유닛·전장 경계를 고려하는 이동, 평타·스킬 범위와 분배율·우선순위를 갖는 피해 대리 수신은 구현되었다. 소환 직후 보호 관계를 자동으로 연결하는 액션과 상태이상 이전은 직업 규칙에서 확장한다.
5. **직업 규칙**: 능력치와 액티브·기본 공격 세트를 바꾸는 변신, 추가 자원, 장비 예외와 전투 전·전투 중 장비 세트 교체, 무기별 독립 공격과 같은 대상 집중 감산, 전투 진입·부활·패배 판정, 부활 후속 규칙, 팀·런타임 규칙 변경, 진영·계열 인원 시너지, 액티브 복제, 예비대 난입과 교대는 구현되었다.

확장 검증은 지속 효과 만료/중첩/해제, 피해 분배 합계, 반사 무한 루프, 소환수 사망/전투 종료, 부활 대기 중 패배, 편집 후 저장·재로드 보존을 포함해야 한다.
