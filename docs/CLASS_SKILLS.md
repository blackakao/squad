# 직업 스킬 등록과 엔진 확장 과제

현재까지 완료된 엔진 기능의 전체 목록은 [스킬 엔진 업데이트 내역](SKILL_ENGINE_CHANGELOG.md)을 참고한다.

> 후속 구현: 스킬별 시전시간(0초 즉시시전), 원형 광역, 독립 소환수와 예제 7개를 추가했다. [현재 엔진 안내](SKILL_ENGINE.md)가 아래 최초 등록 당시 설명보다 우선한다. 일반 광역·일반 소환·스킬별 시전시간은 이제 지원하며, 아래는 원안 전체의 구현 과제를 기록한 과거 목록이다.

[직업 원안](CLASS.MD)에서 현재 실행 가능한 효과로 액티브 30개를 등록했다. 기존 스킬과 캐릭터 장착 구성은 유지한다.

## 편집과 기본값

스킬 화면에서 직업명으로 찾아 수치를 수정하고 캐릭터 수정 화면에서 장착한다. 모두 액티브이며, 원안의 기본스킬은 자동 평타용 basic 슬롯과 다르다. 직업별 장착 제한 및 기본 4개/선택 3개 제한은 아직 없다.

기본 쿨타임 8초, MP 또는 ST 소모 10, 공격력/마력 계수 100%, 강공 150%, 고정 피해 20, 자원 회복 20이다. 근접 사거리 1, 원거리 5, 저격 10이다. 사용자가 조정할 초기값이다.

(기본형)은 원안의 일부 효과만 동작한다는 뜻이다. 미지원 효과는 아래 직업별 표를 참고한다. 모든 스킬은 유닛 공통 시전시간을 따르며, BP 보호막은 만료되지 않는다. 피흡기와 암흑물기는 실제 피해량과 무관하게 마력 50%를 자가 회복한다. 검무 집중은 공격력 25%씩 즉시 6타, 사연격은 25%씩 즉시 4타다. 야전지구력과 불꽃 명상은 지속 회복이 아닌 즉시 자원 회복이다. 혈청형 수혈기는 저장 자원을 사용하지 않는 단일 치유다.

## 미등록 스킬과 필요한 엔진 기능

현재 `applySkillAction`은 피해·회복·이동만 실제 처리한다. `create_field`는 로그만 남기며, 버프·상태·소환·변신은 실행 분기가 없다. `area`, `duration` 필드도 광역/지속 효과를 실행하지 않는다. 패시브는 장착 액티브 실행 대상에서 제외된다. 따라서 아래는 데이터 추가만으로 구현할 수 없다.

## 권장 확장 순서

1. **실행 기능과 편집기 일치**: 미지원 액션 잠금·지원 여부 표시, 스킬별 시전시간/즉시시전, 액션별 독립 대상·최소 거리·사거리 검증, 원형 반경·최대 대상 수·연쇄 대상 선정은 구현되었다. 적 피해와 아군 회복은 별도 대상과 투사체로 실행한다. 상세 동작은 [스킬 엔진 안내](SKILL_ENGINE.md)를 참고한다.
2. **시간 효과와 이벤트**: 상태/버프 인스턴스의 시전자, 대상별 보관, 지속시간, 중첩·갱신, ID/분류/전체 해제, 효과 부여 면역, 주기 피해·회복, 시전 중단과 공통 이벤트, 조건·확률·쿨타임 기반 패시브, 유지시간·간격·피격 중단을 갖는 채널링은 구현되었다. 패시브로 인한 다른 패시브의 발동은 차단한다.
3. **조건과 계산**: 액션별 대상 쿨타임과 대상 저HP 조건, 전투 누적 실제 피해량·이동 거리·대상 전체 또는 특정 ID 중첩·생존한 자기 소환수 수 계수, 직전 액션과 현재 실행의 실제 피해·치유량 전달 및 액션 조합을 통한 피해↔치유 전환, 적중·피격·회복·시전 완료 기준의 다음 N회 소비 효과와 피해 무시, 시전자 자신의 실제 스킬 자원 지불량, 대상 HP·MP·ST·BP 감소와 실제 성공량 전달은 구현되었다.
