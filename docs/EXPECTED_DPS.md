# 기대 DPS

2026-11-03. 표시용 비교 지표이며 실제 전투 DPS나 승률을 의미하지 않는다. 계산 결과는 저장하지 않고 전투 엔진·사용자 데이터를 변경하지 않는다.

## 표시 위치

- 장비 착용: 캐릭터와 무기 선택 시 상세정보에 장착 가능한 슬롯별 기대 DPS를 표시한다. 복사본에 기존 장착 규칙을 적용하므로 양손 점유와 다른 장비의 스탯·스킬 보정까지 반영한다. 실제 장착은 하지 않는다.
- 무기 수치는 **선택한 무기 하나의 공격** 기준이다. 다른 무기의 동시 공격과 집중 감산은 합산하지 않는다. 캐릭터 미선택 시 선택을 안내한다.
- 캐릭터 관리: 추가/수정 창의 스킬 hover·키보드 focus에서 현재 스탯·장비 기반 DPS를 표시한다. 피해 행동이 없는 스킬은 DPS 항목을 생략한다. 선택형 스킬은 기본 선택지를 사용한다.

## 산식·전제

- 방어/저항 0인 단일 대상, 충분한 자원, 이동·투사체 비행·중단 없음. 팀 시너지와 팀 배율, 다른 액티브 스킬과 패시브의 추가 피해 발동은 제외한다. 공통 스탯 계산과 장비 스킬 보정·선택 보정을 재사용한다.
- 직접 피해는 공통 계수 함수로 산출한다. 액티브 DPS = 한 사이클 직접 피해 / (시전시간 + 재사용 대기시간). 시간은 엔진 틱 단위로 환산하며 0초 반복의 하한은 1틱이다.
- 채널링은 지속시간 내 발동 횟수를 반영하고 채널링 시간을 분모에 더한다. 연계는 모든 단계와 마지막 완료 액션의 직접 피해, 단계별 시전·쿨다운을 합산한다.
- 기본 공격은 공격 간격과 시전시간 중 긴 값을 기준으로 한다. 여러 무기 장착 시 선택 무기의 독립 공격 간격·시전시간을 사용하며, 단일 무기는 캐릭터의 적용 능력치와 무기 스킬 시전시간을 사용한다.
- 피해량 0도 유효한 수치다. 하지만 대상 상태·전투 누적값, 패시브 발동 빈도, 지속 피해의 재적용·중첩, 전투 중 능력치 변화 등은 고정 DPS를 보장할 수 없어 `산출 불가`와 이유를 표시한다. 조건부 피해를 임의의 0 DPS로 바꾸지 않는다.
- 소환수 공격은 직접 피해에 포함하지 않는다. 무기 연계·채널링도 현재 고정 DPS 산출 범위 밖이다.

## 검증 상태

JS 문법과 연결·복사본 계산 경로를 정적으로 검토했다. 계산용 Node 시나리오 5개를 준비했으나 최초 실행은 기존 로더의 `document.addEventListener` 모의 객체 누락으로 계산 검증 전 실패했다. 전용 로더에 이벤트 스텁을 보완했으며 프로젝트 규칙에 따라 재실행하지 않았다. 따라서 테스트 통과나 브라우저 표시 검증 완료로 간주하지 않는다.
