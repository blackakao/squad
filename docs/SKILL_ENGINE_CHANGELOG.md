이 문서는 `docs/CLASS.MD`의 직업 스킬을 실제 전투에서 실행하기 위해 추가한 스킬 엔진 기능을 정리한다. 현재 동작의 세부 규칙과 JSON 필드는 [스킬 엔진 안내](SKILL_ENGINE.md), 소환 데이터 관리는 [소환 Entity 관리](ENTITIES.md)를 함께 참고한다.

- 최종 정리일: 2026-10-03
- 핵심 엔진 상태: 구현 완료
- 자동 검증: 148개 테스트 통과
- 수치 정책: 편집 가능한 기본값만 제공하며 최종 밸런스 수치는 사용자가 조정한다.

## 1. 편집기와 데이터 안전성

- 실행 가능한 액션과 미지원 액션을 구분한다. 미지원 액션은 원본 JSON을 보존한 채 편집기에서 잠금 표시한다.
- 미지원 액션이 하나라도 포함된 스킬은 전투에서 전체 실행을 막는다. 일부 액션만 실행된 뒤 자원과 쿨타임이 소모되는 상황을 방지한다.
- 스킬 공통값에 이름, 설명, 슬롯, 시전시간, 쿨타임, 자원 비용을 둔다.
- 스킬 관리 목록의 액션 열을 설명 요약으로 교체했고, 직접 작성한 설명이 있으면 이를 우선 표시한다.
- 캐릭터와 몬스터 모두 사용 스킬을 선택할 수 있다. 무기에 잘못 연결된 패시브나 미지원 스킬은 기본 공격으로 대체한다.
- 이전 JSON 필드는 가능한 한 정규화해 읽고, 알 수 없는 데이터는 임의 변환하지 않는다.

## 2. 시전과 액션 실행

- `castTime: 0`은 즉시시전이다. 양수면 시전 완료 후 액션을 실행한다.
- 스킬 시전시간은 유닛 기본 시전시간과 분리해 설정하며, 이전 데이터처럼 값이 없을 때만 유닛 값을 상속한다.
- 기절, 침묵, 사망, 피해 중단 설정은 진행 중인 시전 또는 채널링을 취소한다.
- 자원은 실제 시전을 시작할 때 한 번 지불하고, 쿨타임은 규칙에 맞는 시점에 시작한다.
- 여러 액션을 가진 스킬은 액션마다 독립적으로 대상, 사거리, 효과를 판정한다. 적 피해와 아군 회복을 한 스킬에 함께 넣을 수 있다.
- 투사체가 필요한 액션은 도착 시점에 대상을 다시 검증하며, 앞선 투사체 결과를 사용하는 후속 액션은 명중 이후 이어서 실행한다.

## 3. 대상, 사거리, 광역과 연쇄

지원 대상 그룹은 다음과 같다.

| 값 | 의미 |
| --- | --- |
| `self` | 시전자 자신 |
| `ally` | 같은 진영의 유효한 아군 |
| `enemy` | 반대 진영의 유효한 적군 |
| `summon` | 시전자가 직접 소유한 살아 있는 소환수 |

- 액션마다 주장비 사거리 또는 직접 입력 사거리를 선택한다.
- `minRange`와 최대 사거리 경계는 포함 판정한다. 광역 액션의 최소 거리는 범위 내부가 아니라 중심 대상 선택에 적용한다.
- `targetHpBelow`로 HP 비율 조건을, `targetCooldown`으로 같은 액션이 같은 대상에게 다시 적용되는 간격을 설정한다.
- `area`와 `maxTargets`로 원형 광역과 대상 수를 제한한다. 회복은 부족한 자원을 가진 대상, 자원 감소는 해당 자원이 남은 대상을 우선한다.
- `chainCount`와 `chainRange`로 첫 대상에서 가까운 미방문 대상으로 이어지는 연쇄를 만든다.
- 시전 중에는 점선 범위와 진행 원호, 투사체 이동 중에는 도달 범위, 발동 시에는 짧게 남는 충돌 범위를 표시한다.

## 5. 상태, 버프와 채널링

- 상태는 기절, 이동 불가, 침묵과 주기 효과 전용 상태를 지원한다.
- 버프는 고정값, 기본 능력치 비율, 최종값 고정, 다른 능력치 전환을 지원한다.
- 추가 버프 모드로 다음 1회 스킬 보정, 피해 반사, 피해 무시, 피해 대리, 상태·효과 면역을 지원한다.
- 효과마다 ID, 이름, 일반·물리·마법 분류, 이로운·해로운 성격, 해제 가능 여부를 저장한다.
- 지속시간 0은 전투 종료 또는 해제까지 유지한다. 재적용은 시간 갱신 또는 중첩 증가를 선택한다.
- 사용 횟수 효과는 적중, 피격, 회복, 시전 완료 중 하나에서 소모한다.
- 주기 효과는 독립 간격으로 피해 또는 회복을 적용하며, 최초 시전자와 패시브 여부를 유지한다.
- 채널링은 준비 시전, 유지시간, 반복 간격, 피해 중단 여부를 가지며 자원을 한 번만 지불한다.

## 6. 실행 결과와 계산계수

기본 능력치 계수 외에 다음 런타임 값을 후속 액션 계산에 사용할 수 있다.

| 계수 | 의미 |
| --- | --- |
| `actualDamageTotal` | 전투 중 시전자가 실제로 준 누적 HP+BP 피해 |
| `moveDistanceTotal` | 충돌 보정 후 실제 누적 이동 거리 |
| `targetEffectStacks` | 대상의 모든 상태·버프 중첩 합계 |
| `targetEffectIdStacks` | 지정한 효과 ID의 대상 중첩 합계 |
| `ownedSummonCount` | 살아 있는 자기 소환수 수 |
| `previousActualDamage` / `executionActualDamage` | 직전 피해 액션 / 현재 실행의 누적 실제 피해 |
| `previousActualHealing` / `executionActualHealing` | 직전 회복 액션 / 현재 실행의 누적 실제 회복 |
| `previousResourceDrained` / `executionResourceDrained` | 직전 / 현재 실행의 실제 자원 감소량 |
| `resourceSpentTotal` | 이번 스킬이 실제 지불한 전체 자원 |
| `hpResourceSpent` 등 | 이번 스킬이 자원별로 실제 지불한 양 |

과잉 피해와 최대치를 넘은 회복은 실제 결과에서 제외한다. 이를 이용해 흡혈, 치유량의 피해 전환, 자원 소모 비례 효과 등을 여러 액션 조합으로 만든다.

## 7. 이동, 충돌과 지속 필드

- 돌진은 캐릭터만 이동하고 투사체를 만들지 않는다. 이동 뒤 후속 피해를 적용한다.
- 순간이동은 목적지가 다른 유닛과 겹치면 실패한다. 돌진과 강제 이동은 유닛 및 전장 경계 앞에서 멈춘다.
- 속박은 자발 이동과 돌진을 막지만 넉백·밀치기·끌어오기는 막지 않는다.
- 지속 필드는 생성 순간의 위치에 고정되고 매 간격마다 범위 안 대상을 다시 찾는다.
- 필드 지속시간과 필드가 부여한 상태·버프 지속시간은 서로 독립적이다.
- 필드, 광역, 연쇄는 같은 대상·면역·중첩·최대 대상 수 규칙을 사용한다.

## 8. 소환 Entity 시스템

- Entity는 `data/entities/*.json`에서 스킬과 독립적으로 관리하고, 스킬에는 `entityId`만 저장한다.
- 스킬 편집 화면 안에서 Entity 선택, 검색, 생성, 수정, 복사, 삭제, 사용처 확인이 가능하다.
- 사용 중인 Entity는 삭제를 막는다. 공용 Entity 수정과 현재 스킬용 새 Entity 저장을 구분한다.
- Entity에는 HP·MP·ST·공격·마력·방어·저항·이동속도·공격 간격·시전시간·사거리와 AI를 저장한다.
- 근접, 원거리, 치유, 설치형 AI를 지원하고 저장 전 독립 전투 미리보기를 제공한다.
- 소환수는 소유자, 소환 스킬, 수명, 개별 한도와 진영 전체 한도를 가진다. 소환수만 살아 있어도 전투가 계속된다.
- 소환 중심은 시전자 또는 선택 대상이며, 소환 순간 시전자의 현재 전투 능력치를 비율로 계승할 수 있다.
- 소환수는 소유자가 받을 피해를 비율·우선순위에 따라 대신 받거나 해로운 상태를 이전받을 수 있다.
- `내 소환수` 대상은 다른 아군과 다른 소유자의 소환수를 제외한다.
- 소환수 명령은 정지, 행동 재개, 소환자 옆 복귀, 소환 해제를 지원하며 광역 명령도 가능하다.

## 9. 직업 규칙 확장

- 캐릭터와 몬스터는 HP·MP·ST·BP 외에 사용자 정의 자원을 가질 수 있다.
- 캐릭터는 최대 3개 장비 세트와 추가 무기 슬롯을 가지며 양손무기 점유 규칙을 설정한다.
- 여러 무기는 각자 시전시간, 사거리, 쿨타임, 자원 비용을 사용한다. 같은 대상을 집중 공격하면 설정된 감산을 적용한다.
- 전투 진입 지연, 자동 부활 횟수·대기시간·회복 비율·복귀 위치·부활 직후 무적을 지원한다.
- 예비대는 자동 보충, 영구 교대, 시간제 교대, 임시 증원을 지원한다.
- 팀은 피해·회복·자원 비용·쿨타임 배율과 진영·계열 인원 기반 시너지를 가진다.
- 런타임 규칙은 받는 피해·회복, 장비 효과, 팀 시너지, 특정 또는 전체 스킬 사용을 일시적으로 변경한다.
- 변신은 능력치와 스킬 세트를 교체하며 만료·사망 시 정확한 원래 상태로 복원한다.
- 스킬 복제는 원본과 독립된 런타임 ID와 쿨타임을 사용하고 다음 전투에 남지 않는다.

## 10. 전투 이벤트와 기록

지원 이벤트:

`cast_start`, `cast_complete`, `cast_interrupt`, `hit`, `damaged`, `heal`, `resource_drain`, `death`, `revive`, `battle_entry`, `skill_copy`, `reserve_swap`, `rule_override`, `channel_start`, `channel_tick`, `channel_complete`, `channel_interrupt`, `field_create`, `field_tick`, `field_expire`, `forced_move`, `damage_redirect`, `transform_start`, `transform_end`, `summon_command`.

- 이벤트는 전투 틱, 출처, 대상, 스킬, 실제 수치, 피해 종류, 자원, 사유와 패시브·주기 여부를 스냅샷으로 기록한다.
- 이벤트 구독은 중첩 깊이와 한 번의 연속 처리량을 제한해 무한 재귀를 방지한다.
- 패시브는 자신의 적중, 피격, 시전 완료, 회복, 적 처치 조건과 확률·쿨타임을 사용한다.
- 패시브가 다른 패시브를 연쇄 발동하지 않도록 표시를 전파한다.
- 전투 중 최근 1,000건을 보관하고 상세 패널에는 필터별 최근 200건을 표시한다.
- 전투 종료 시 최근 1,000건을 기록 JSON에 저장하며 전투 기록 화면에서 펼쳐 볼 수 있다.

## 데이터 호환 원칙

- 새 필드는 기본값을 제공해 기존 스킬을 그대로 불러온다.
- 잘못된 숫자는 허용 범위로 제한하고, 실행 의미를 알 수 없는 액션은 잠근다.
- Entity 수정은 이를 참조하는 다음 전투부터 반영하지만 이미 생성된 전투 개체의 능력치는 바꾸지 않는다.
- 전투 중 생성한 효과, 복제 스킬, 소환수, 필드와 규칙 덮어쓰기는 원본 캐릭터·몬스터·스킬 JSON에 역으로 저장하지 않는다.
- 이전 전투 기록에 이벤트가 없으면 빈 배열로 처리한다.
