# 스킬·시너지 개별 그림

2026-10-15. 공통 단어/카테고리 아이콘 매핑과 독립적으로 각 스킬·시너지 레코드의 그림을 관리한다.

- 스킬/시너지 추가·수정 창의 그림 편집기를 사용한다. 현재 선택 미리보기, 기존 그림 보관함, 새 파일 추가, 선택 해제를 제공한다.
- 파일 추가는 기존 이미지 업로드 API를 재사용한다. PNG/JPG/WEBP/GIF 최대 5MB를 받으며 업로드 중에는 선택 변경을 막고 항목 저장 시 대기 안내를 표시한다.
- 업로드는 즉시 파일 보관함에 저장한다. 항목과의 연결은 스킬/시너지 저장 시 적용한다. 편집 취소·선택 해제·항목 삭제는 다른 항목이 재사용할 수 있는 이미지 파일을 삭제하지 않는다.
- 스킬은 `assets/images/skills/`, 시너지는 `assets/images/synergies/`를 사용한다. 각 폴더 바로 아래 이미지 목록을 `GET /api/assets/skills` 및 `GET /api/assets/synergies`로 조회한다. 업로드는 같은 URL의 POST를 사용한다. 빈 폴더는 빈 목록을 반환한다.
- 목록은 이름과 경로를 반환하며 허용 확장자 파일만 포함하고 심볼릭 링크는 제외한다. UI는 허용된 로컬 그림 경로만 이미지로 표시한다.
- 각 레코드에 선택적 문자열 `icon`을 저장한다. 기존 필드 없는 데이터는 그림 없이 표시되고 대량 마이그레이션하지 않는다. 스킬 정규화는 icon을 보존한다.
- 관리 표의 이름 옆과 팀 편성의 활성 시너지 이름 옆에 그림을 표시한다. 스킬/시너지 효과·조건·전투 계산에는 사용하지 않는다.
- 서버 재시작이 필요하다. 조회/업로드 실패 시 편집창에 오류와 재시도 방법을 표시한다.

검증: 작업 규칙에 따라 JS/Python 문법 및 저장·정규화·DOM 경로를 정적으로 확인했다. 자동 테스트와 실제 브라우저 업로드/저장 검증은 수행하지 않았다.
