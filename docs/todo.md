## 우선 작업

새 착수 순서는 미확정이다. 기존 재개 메모와 선행 조건에 따라 다음 대상을 확인한다(중복 체크 항목은 만들지 않는다).

- 브라우저 검증이 요청되면 아래 V1~V10의 미완료 조건을 구분해 확인한다. ChromeDriver/브라우저 연결 문제와 테스트 제한은 AGENTS 기준이다.
- 저장 자료 중복 정리는 S2의 참조 전환·격리 검증이 먼저이며, 기존 파일 삭제·추적 해제는 이후 사용자 승인이 필요하다.
- 아이콘 I1·I2는 사용자 대응 확정/자산 준비, GLB G1~G5는 규격·대상 확정이 선행한다. [GLB/Legacy 정적 조사](GLB_LEGACY_AUDIT.md)의 전환 계획은 후속 범위 결정 자료이며 실행 승인이 아니다.
